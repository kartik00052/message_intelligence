L1 CANDIDATE DATASET

Share this entire folder with candidates.

mandatory_demo_ids.csv lists the 15 message IDs that must be shown in the video.

Candidates must not publish the dataset in a public repository or send raw messages to external AI services. All sensitive-looking values are fictional but must still be masked as required by the assignment.
